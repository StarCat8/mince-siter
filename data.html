MINCE provides two complementary data products: a stellar parameters and abundance catalog, and reduced FITS spectra for each observed star.

Catalog

⭐ Stellar parameters & chemical abundances

102 metal-poor giants with atmospheric parameters (Teff, log g, [Fe/H], ξ) and chemical abundances for 30+ elements including neutron-capture tracers (Sr, Y, Zr, Ba, La, Ce, Eu, …). Updated with each publication.

CSV 102 stars 30+ elements NLTE corrections
Open interactive visualizer → Download catalog CSV
Spectra

📂 Reduced spectra (FITS files)

Reduced, wavelength-calibrated 1D spectra for all 102 observed stars. Each star may have one or more spectra from different instruments. Files follow the naming convention MINCE_<STARNAME>_<INSTRUMENT>_<DATE>.fits. Hosted on GitHub Releases for direct download.

FITS 102 spectra R ≥ 50,000 S/N ≥ 100
Browse & download FITS → GitHub repository
ℹ️ FITS files are hosted on GitHub Releases. Each star's available files are listed on the GitHub release page. If you need a bulk download of all spectra, see the README in the repository for a wget script.
How to access the data

Getting started

01 — VISUALIZER

Explore online

Use the interactive browser to plot any pair of abundance ratios, filter by instrument, or search by star name. No installation needed.

02 — CSV DOWNLOAD

Download the catalog

The catalog CSV contains one row per star with all atmospheric parameters and abundance columns. Load it in Python, R or TOPCAT.

03 — FITS SPECTRA

Download spectra

Find your star on the GitHub Releases page, click the FITS file to download. Use astropy.io.fits or IRAF to open it.
